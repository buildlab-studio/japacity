# Design pages

Why the game is the way it is, one system to a page. Read a page when a rule seems wrong. The rules themselves are on the rule pages in `../rules/`, the decisions in `../decisions/`, and the facts the numbers rest on in `../research/`.

Each page is a design doc in the standard shape set out in [How rules, decisions and designs are written](../site/built/working.md#how-rules-decisions-and-designs-are-written): the context and scope, the goals and non-goals, the design, and the alternatives considered. The page numbers are permanent ids. Pages cited by section number keep their section numbers, with the context and goals in an unnumbered preface and the alternatives as the last section.
